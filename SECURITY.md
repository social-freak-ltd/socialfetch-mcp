# Security Policy

## Reporting a Vulnerability

If you believe you have found a security issue in the Social Fetch MCP integration, please contact:

```text
support@socialfetch.dev
```

Please include enough detail to reproduce the issue, including the MCP client, request flow, and any relevant `meta.requestId` values returned by Social Fetch.

Do not open public GitHub issues for sensitive vulnerabilities.

## Scope

This repository contains public documentation, examples, assets, and registry metadata for the hosted Social Fetch MCP server.

The production MCP server runs at:

```text
https://api.socialfetch.dev/mcp
```
